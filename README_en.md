> **Dead by Daylight Randomizer & Hub** is a compact client-side web application designed for DBD players and streamers. Randomize characters, track match statistics, and take on the custom "LUCKY" challenge mode—all within a single dark-themed interface.

---

## ⚡ Key Features

### 🎯 Randomizer Wheel
* **Quick Selection:** Select or deselect all characters with a single click.
* **Filtering:** Built-in search bar and flexible pool customization.
* **Exclusion Mode:** Automatically removes selected characters from the wheel after spinning.
* **Presets:** Export and import your custom character lists in `.json` format.

### 📊 Escape Stats Tracker
* **Personal & Team Analytics:** Separate tracking for escapes and sacrifices/kills.
* **Win Rate Calculation:** Automatic percentage calculation of successful matches.
* **Multi-mode Support:** Switch seamlessly between **1vs4** and **2vs8** modes.
* **Local Backup:** Export your entire session stats to a local file.

### 🎲 "LUCKY" Challenge Mode
* **Multi-Wheel System:** Currency wheel, modifier wheel, and killer wheel.
* **In-Game Economy:** Bank balance tracking, match outcome history, and an item shop.
* **Progress Saving:** Full export and import support for your ongoing challenge progress.

## ⚙️ Technical Highlights

* **Zero Backend:** Runs 100% on the client side (Client-side HTML/JS).
* **Local Storage:** Session data remains in memory (manual JSON export available).
* **Responsive Design:** Dark, aggressive visual aesthetic inspired by the Entity's Realm.
* **Localization:** Full support for **EN / RU** languages.
